# AI Project Lab MVP v1.0

Collaborative web app for a one-day team AI project lab: shared visual maps, stage gates, team roles, decisions, AI-use tracking with credits, huddles, prototype versions, an instructor dashboard, a Prototype Gallery, and a de-identified pilot export.

- Setup and deployment: `SETUP.md`
- Stage rules and build decisions: `GATES.md`
- Accessibility: `compliance-notes.md`
- Database: `supabase/migrations` (run in order), tests in `supabase/tests`

Stack: Next.js 15, React 19, TypeScript, Tailwind CSS, Supabase (Auth, Postgres, Realtime, Row Level Security).
